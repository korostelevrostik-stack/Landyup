# 👿 Адвокат Дьявола

Telegram Mini App — суди души и зарабатывай монеты.

## 🚀 Демо
[Ссылка на игру](https://твой-ник.github.io/devils-advocate/)

## 📱 Как играть
1. Читаешь историю грешника
2. Нажимаешь ⬆️ «В РАЙ» или ⬇️ «В АД»
3. Угадал → +50 🪙, ошибся → -20 🪙
4. Серия из 5 спасений → бонус +50 🪙

- Telegram Mini App (в планах)
